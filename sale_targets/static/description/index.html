🎯 Sales Targets | أهداف المبيعات

Track, manage and reward your sales team | تتبع وإدارة ومكافأة فريق المبيعات

✨ Key Features | المميزات الرئيسية

🎯 Set Targets | تحديد الأهداف

Set sales targets for each salesperson with a specific time period.
حدد أهداف مبيعات لكل مندوب مع تحديد الفترة الزمنية بسهولة.

📊 Auto Tracking | متابعة تلقائية

Automatically calculates actual sales and achievement percentage from sale orders.
حساب تلقائي للمبيعات الفعلية ونسبة الإنجاز من أوامر البيع.

🏆 Rewards System | نظام المكافآت

Automatically calculate rewards based on achievement percentage.
احسب المكافآت تلقائياً بناءً على نسبة تحقيق الهدف.

📅 Daily Target | الهدف اليومي

Calculate the required daily target based on remaining days and current sales.
احسب الهدف اليومي المطلوب بناءً على الأيام المتبقية والمبيعات الحالية.

🔔 Smart Alerts | تنبيهات ذكية

Automatic alerts to salesperson when falling behind on target.
تنبيهات تلقائية للمندوب عند التأخر في تحقيق الهدف.

🏅 Leaderboard | لوحة المتصدرين

Compare salesperson performance and who achieved the highest percentage.
قارن أداء المندوبين ومن حقق أعلى نسبة إنجاز.

📋 Professional PDF Report | تقرير PDF احترافي

Print a detailed report for each target including all data and statistics.
اطبع تقرير مفصل لكل هدف يشمل جميع البيانات والإحصائيات.

🎨 Modern Blue Theme | ثيم أزرق عصري

Beautiful professional interface with colored cards and progress bars.
واجهة احترافية جميلة مع كروت ملونة وشريط تقدم.

⚙️ How it works | كيف يعمل

1️⃣ Create Target | إنشاء هدف

Create a new target, assign salesperson, set amount and date range.

إنشاء هدف جديد، تعيين المندوب، تحديد المبلغ والفترة الزمنية.

2️⃣ Activate | تفعيل

Click Activate button to start tracking the target.

اضغط زرار التفعيل لبدء متابعة الهدف.

3️⃣ Track | متابعة

System automatically calculates actual sales and daily required target.

النظام يحسب تلقائياً المبيعات الفعلية والهدف اليومي المطلوب.

4️⃣ Reward | مكافأة

Upon completion, system calculates reward and sends achievement email.

عند الإنهاء، النظام يحسب المكافأة ويرسل إيميل الإنجاز.
