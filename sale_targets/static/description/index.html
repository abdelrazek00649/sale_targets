⚙️ كيف يعمل النظام | How It Works
4 خطوات بسيطة لإدارة أهداف المبيعات
1
إنشاء هدف | Create
أنشئ هدف جديد، حدد المندوب والمبلغ المستهدف والفترة الزمنية
2
تفعيل | Activate
اضغط زرار التفعيل لبدء متابعة الهدف وتتبع المبيعات تلقائياً
3
متابعة | Track
النظام يحسب تلقائياً المبيعات الفعلية والهدف اليومي والأيام المتبقية
4
مكافأة | Reward
عند الإنهاء، النظام يحسب المكافأة ويرسل إيميل الإنجاز تلقائياً
